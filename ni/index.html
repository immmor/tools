直接双击 index.html 即可运行（全部使用传统 <script>，无构建、无依赖、无网络请求）。
若以 file:// 打开，浏览器会限制 data: 动态 import、Blob Worker 与部分 WebCrypto 能力，这些项会标记为 SKIP 并自动走 JS 降级实现；用本地静态服务打开可解锁全部特性。
API 演练为浏览器内的模拟网关（OBF.api.request(method, path, opts)），演示账号 admin / ni-2026，token 有效期 5 分钟；换成真实后端时，签发与校验必须放在服务端，客户端只保留取 token 的逻辑。
只有确定性输出能进密钥：探测型技术（DevTools / 时间差 / 栈指纹 / 一次性 getter / Proxy）作为校验闸门，异步或环境受限的通道（Blob / data: import / Worker）不进密钥，否则 token 会跨浏览器失效。
本项目仅用于代码保护 / 逆向对抗的教学演示，反调试探针均不实际阻断调试器。为便于观察，各层 API 挂在了 window.OBF 上；真实交付时应把全部模块内联进单一闭包、去掉自检与日志，逆向者就只能靠动态调试逐层还原。
