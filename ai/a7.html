// 文档

三分钟，接上 API

标准 OpenAI 兼容格式，你原来的代码几乎不用改。把地址换成中转站入口就行。

cURL 示例
curl https://你的中转站/v1/chat/completions \
  -H "Authorization: Bearer 你的密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role":"user","content":"你好"}],
    "stream": true
  }'
JavaScript 示例
const res = await fetch(
  "https://你的中转站/v1/chat/completions",
  { method:"POST",
    headers:{ "Authorization":"Bearer 你的密钥",
              "Content-Type":"application/json" },
    body: JSON.stringify({
      model:"deepseek-chat",
      messages:[{role:"user",content:"你好"}],
      stream:true }) });
const reader = res.body.getReader();  // 流式读取

提示：浏览器直连部分厂商会被跨域拦，最稳的是把地址指向你自己的 OpenAI 兼容中转（比如 One API / New API）。所有密钥都只存在你本地浏览器里。

// 关于

这玩意儿，到底干啥的

简单说，AI 中转站就是个“模型的统一入口”。你把各家大模型的密钥往里一塞，它就帮你在一个界面里随意切换、统一调用。

不用再为“这个模型在 A 家、那个在 B 家”来回切账号；也不用每接一家就改一遍代码——它对外暴露的是标准的 OpenAI 兼容接口，你原来的调用方式基本原样能用。

密钥只存在你自己的浏览器里，不上传到任何服务器。想更稳，就接一个你自己部署的中转地址，所有流量走你这边。
