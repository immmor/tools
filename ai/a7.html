Python OpenAI SDK 接入方式

只需要修改 `base_url` 和 `api_key` 两个参数即可无缝无感切换：

from openai import OpenAI

client = OpenAI(
    # 替换为你从 YELLOW AI HUB 复制的 Key
    api_key="sk-yellow-your-actual-api-key",
    # 替换为中转站的 Base URL
    base_url="https://api.yellow-ai-hub.com/v1"
)

response = client.chat.completions.create(
    model="deepseek-r1",
    messages=[
        {"role": "user", "content": "用大白话解释什么是量子纠缠？"}
    ]
)

print(response.choices[0].message.content)
